# Data
Saved assignment and course data is stored here.

## Course data
Courses are formatted as:
<COURSE_NAME>,<CURRENT_GRADE>,<CATEGORY_1_NAME>,<CATEGORY_1_VALUE>,<CATEGORY_2_NAME>,<CATEGORY_2_VALUE>,...
 
### Example
Data Structures,92.5,Assignments,0.25,LeetCode,0.20,Midterm,0.15,Project,0.20,Final,0.25


## Assignment data
Assignments are formatted as:
<COURSE_NAME>,<ASSIGNMENT_NAME>,<CATEGORY>,<DUE_YEAR>,<DUE_MONTH>,<DUE_DAY>

### Example
Data Structures,LeetCode 1,LeetCode,2026,8,26
