# Data
Saved assignment and course data is stored here.

## Course data
Courses are formatted as:
{COURSE_1_NAME},{CURRENT_GRADE}, {>}, {CATEGORY_1_NAME},{CATEGORY_1_VALUE},{ASSIGNMENT_NAME},{POINT_VALUE},{DUE_YEAR},{DUE_MONTH},{DUE_DAY}, {>}, {CATEGORY_2_NAME},{CATEGORY_2_VALUE},{ASSIGNMENT_NAME},{POINT_VALUE},{DUE_YEAR},{DUE_MONTH},{DUE_DAY} {\n}...
{COURSE_2_NAME},{CURRENT_GRADE},{CATEGORY_1_NAME},{CATEGORY_1_VALUE},{ASSIGNMENT_NAME},{POINT_VALUE},{DUE_YEAR},{DUE_MONTH},{DUE_DAY}, {>} {CATEGORY_2_NAME},{CATEGORY_2_VALUE},{ASSIGNMENT_NAME},{POINT_VALUE},{DUE_YEAR},{DUE_MONTH},{DUE_DAY} {\n}...
...

### Note
Categories are separated by > to differentiate between assignments and categories.
 
### Example
Data Structures,92.5, >, Assignments,0.25,Assignment 1,90,2026,8,26,Assignment 2,80,2026,8,26, >, LeetCode,0.20,Midterm,0.15,Project,0.20,Final,0.25,LeetCode 1,70,2026,8,26,\n
